# Knowledge Base

Clinical and educational content for the RAG chatbot. Add `.txt`, `.md`, or `.json` files in the category folders below, then run:

```bash
python server/rag/ingest.py
```

## Categories

| Folder | Topics |
|--------|--------|
| `migraine_basics/` | types, phases, anatomy |
| `triggers/` | food, hormones, light |
| `treatments/` | meds, therapies, dose |
| `lifestyle/` | habits, routines |
| `weather/` | pressure, humidity |
| `sleep/` | schedule, disorders |
| `stress/` | management, anxiety |
| `nutrition/` | diet, hydration, caffeine |
| `faq/` | common questions |
| `emergency/` | red flags, when to call |
| `medications/` | side effects, interactions |
| `hormones/` | menstrual, pregnancy |
| `tracking/` | diary, patterns, logs |
| `comorbidities/` | anxiety, depression |
| `chatbot_rules/` | scope, disclaimers |
